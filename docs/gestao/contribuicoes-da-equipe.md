# Contribuições da Equipe

Este documento registra as contribuições efetivamente realizadas no desenvolvimento do **Aura Smart Apartment**, separando o planejamento inicial da execução final do MVP.

A intenção é preservar o histórico do projeto de forma objetiva. Contribuições parciais ou iniciais também são registradas.
